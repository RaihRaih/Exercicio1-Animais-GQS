## Descrição

O sistema representa animais utilizando herança e polimorfismo em Java. A classe Animais funciona como superclasse, contendo características e comportamentos comuns, enquanto as classes Gato e Cachorro são subclasses com características e métodos específicos.

No programa principal, são criados objetos de Gato e Cachorro, que são armazenados em uma coleção do tipo Animais. O método comer() é sobrescrito pelas subclasses, permitindo demonstrar o polimorfismo, pois a mesma chamada de método apresenta comportamentos diferentes de acordo com o tipo do animal.
